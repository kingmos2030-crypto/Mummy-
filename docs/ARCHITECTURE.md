# Mummy شافت — خطة الهندسة (Architecture Plan)

> هذه الوثيقة تسبق التنفيذ وتغطّي البنود A → J المطلوبة في المواصفة، ثم المراجعة الذاتية
> (البند 26) والتحسينات التي أُضيفت تلقائيًا.

المنتج: **مكتشف وسائط + متتبّع شخصي + يوميات مشاهدة**.
ليس منصّة بث، ولا يستضيف أي ملفات فيديو، ولا يوفّر روابط مشاهدة/تحميل/تورنت.
البيانات الخارجية = بيانات عامة (Metadata + صور) من TMDB / Jikan / TVmaze فقط.

---

## A. خطة البنية (Architecture Plan)

```
المتصفح (React 19 + Vite + Tailwind v4, RTL)
        │  fetch نسبي إلى /api فقط  (لا مفاتيح، لا نداء مباشر لأي API خارجي)
        ▼
Express 5 (طبقة الخدمة — تعمل محليًا وكدالة Vercel serverless واحدة)
   ├── routes/        تحقّق من المدخلات + تشكيل الاستجابة
   ├── services/      discovery (دمج المزوّدات) · library (بياناتي) · stats
   ├── providers/     tmdb · jikan · tvmaze · offline (احتياطي)
   ├── lib/           http (مهلة/إعادة محاولة/throttle) · cache · normalize · validation
   └── db/            libSQL (@libsql/client): file: محليًا | HTTPS إلى Turso في السحابة
        ▼
SQLite  ├── مرآة البيانات الخارجية (قابلة للحذف وإعادة البناء)
        └── بياناتي الشخصية (المصدر الوحيد للحقيقة)
```

مبادئ:

1. **صيغة داخلية موحّدة** (`normalizedMedia`) — الواجهة لا تعرف أي مزوّد أنتج البيانات.
2. **فصل صارم** بين بيانات الـ API (مرآة مؤقتة) وبياناتي (دائمة).
3. **تدهور رشيق**: فشل مزوّد ⇒ نتائج المزوّدات الأخرى ⇒ نسخة مخزّنة (stale) ⇒ كتالوج محلي.
4. **جاهزية التوسع**: كل شيء مربوط بـ `user_id` منذ اليوم الأول؛ إضافة المصادقة لاحقًا = استبدال middleware واحد.
5. **سيرفرلس أولًا**: طبقة DB غير متزامنة بالكامل (async)، جولات مُجمَّعة (IN/JOIN بدل N+1)
   لأن القراءة/الكتابة في الإنتاج رحلات HTTP إلى Turso، لا استدعاءات محلية رخيصة.
6. **لا اعتماديات أصلية**: لا better-sqlite3 ولا node-gyp ⇒ `npm install` ينجح في كل
   بيئة (بما فيها خط بناء Vercel نفسه).

## B. مخطط قاعدة البيانات (Database Schema)

| الجدول | الدور | ملاحظات |
| --- | --- | --- |
| `users` | المالك/المستخدمون | وضع مستخدم واحد الآن، الجدول جاهز للتعدد |
| `media` | العمل بصيغة موحّدة | مرآة للبيانات الخارجية + `fetched_at` للتحديث |
| `media_sources` | (media_id, source, source_type, source_id) | **UNIQUE** ⇒ منع التكرار عبر TMDB/MAL/TVmaze/IMDb |
| `seasons` | المواسم | UNIQUE(media_id, season_number) |
| `episodes` | الحلقات | UNIQUE(media_id, season, episode) |
| `personal_entries` | تجربتي | UNIQUE(user_id, media_id) ⇒ لا سجل مكرر |
| `watch_progress` | حالة كل حلقة | UNIQUE(entry_id, episode_id) |
| `viewing_history` | سجل النشاط | append-only |
| `tags` / `entry_tags` | وسوم مخصّصة | UNIQUE(user_id, name) |
| `api_cache` | ردود المزوّدات | مفتاح + انتهاء صلاحية + علم نجاح/فشل |

حذف عمل من مكتبتي يحذف بياناتي فقط؛ المرآة تبقى (مفيدة للكاش وللبحث لاحقًا).

## C. خطة تكامل الـ APIs

| المزوّد | الاستخدام | المفتاح | الحدود |
| --- | --- | --- | --- |
| TMDB | أفلام/مسلسلات: تفاصيل، طاقم، مواسم، حلقات، إعلانات، صور | مفتاح مجاني | سخيّ (~50 طلب/ثانية) + شرط الإسناد |
| Jikan (MAL) | الأنمي: تفاصيل، شخصيات، طاقم، حلقات، تقييمات | بدون مفتاح | ~3/ثانية، 60/دقيقة ⇒ throttle داخلي |
| TVmaze | المسلسلات: مواسم/حلقات/تواريخ عرض/صور — واحتياطي لـ TMDB | بدون مفتاح | ~20/10 ثوانٍ |
| Offline catalog | احتياطي محلي عند انقطاع الشبكة | — | كتالوج محدود مُعلَن عنه في الواجهة |

سلاسل الاحتياط: تفاصيل مسلسل بلا حلقات في TMDB ⇒ TVmaze عبر IMDb id.
حلقات الأنمي: Jikan ⇒ TVmaze. الترجمة العربية الناقصة في TMDB ⇒ إعادة الطلب بالإنجليزية.

## D. بنية البحث

1. تنفيذ متوازٍ على المزوّدات المناسبة لنوع الوسيط المطلوب (`Promise.all` مع التقاط الأخطاء لكل مزوّد).
2. **الدمج**: مطابقة بالمعرّفات الخارجية ⇒ ثم بالعنوان المُطبَّع + سنة الإصدار.
3. **التطبيع العربي**: إزالة التشكيل، توحيد أ/إ/آ، ى→ي، ة→ه، حذف الرموز.
4. **الترتيب**: تطابق تام > بداية العنوان > تضمين > **تشابه ضبابي (Damerau–Levenshtein على
   مستوى العبارة والكلمات)** > العنوان الأصلي/البديل + وزن للتقييم وعدد المصادر —
   فبحث «interstelar» أو «one peice» يُرجِع العمل الصحيح.
5. الكتالوج المحلي يدمج نتائجه دائمًا (بحث رخيص متسامح مع الأخطاء) ويكون الملاذ عند غياب الشبكة.
6. كاش 6 ساعات لكل استعلام، وإلغاء الطلب السابق عند الكتابة (AbortController).

## E. بنية الصفحات

`/` الرئيسية · `/search` الاكتشاف · `/discover/:source/:type/:id` و`/title/:mediaId` صفحة العمل ·
`/library` مكتبتي · `/watchlist` أريد مشاهدته · `/stats` الإحصائيات · `/profile` ملفي ·
`/history` سجل المشاهدة · `/tags` الوسوم · `*` صفحة 404.

## F. بنية المكوّنات

`Layout` (رأس + بحث + تنقّل سفلي للجوال + Toasts) · `MediaCard` · `PosterArt` (بديل مولَّد للصور المفقودة) ·
`Shelf` (رفوف أفقية) · `RatingInput` (0→10 بخطوة 0.25) · `EntryEditor` (نموذج «تجربتي») ·
`EpisodeTracker` · `ui.jsx` (Modal / Empty / Error / Skeleton / Spinner) · `AppContext` (خيارات، وسوم، تنبيهات، إبطال الكاش).

## G. خطة الأمان

- المفاتيح على الخادم فقط (`.env`), ولا متغيّر `VITE_*` يحمل سرًّا.
- تحقّق Zod لكل مدخل + تعقيم الملاحظات (إزالة HTML وأحرف التحكّم).
- استعلامات مُعلَّمة (prepared statements) ⇒ لا حقن SQL.
- Helmet + CORS مضبوط + حدّ 300 طلب/دقيقة + حدّ حجم الجسم 256KB.
- كل استعلام شخصي مقيّد بـ `user_id` (جاهز للمصادقة).
- صفحات البيانات الشخصية `noindex`.

## H. خطة الأداء

كاش SQLite للردود (بحث 6س / تفاصيل 24س / رائج 12س) + مرآة محلية للتفاصيل + مهلة 8 ثوانٍ وإعادة محاولة واحدة +
throttle لـ Jikan + تقسيم الحزمة (lazy routes) + صور كسولة + عرض حتى 400 حلقة مع بحث/فلترة (One Piece لن يكسر الصفحة).

## I. البنية المجانية

**Vercel** (هوستنغ + دوال serverless للـ API) + **Turso** (قاعدة SQLite بعيدة عبر HTTPS) —
كلاهما بطبقة مجانية تكفي مستخدمًا واحدًا بفارق كبير. الواجهة تُبنى بـ `vite build`
وتُقدَّم كملفات ساكنة من `client/dist` مع تمرير SPA في `vercel.json`، بينما يعمل تطبيق
Express كاملًا داخل دالتَي `api/index.js` و`api/[...all].js`.
بدائل ذاتية الاستضافة (Render / Railway / Fly / VPS): ملف libSQL مضمّن + `npm start`.
لا تخزين صور (نستهلك روابط المزوّدات مباشرة) · كل الـ APIs مجانية.

## J. المزايا الناقصة/تحسينات أُضيفت تلقائيًا

سجل نشاط تلقائي · «حتى هنا» و«موسم كامل» للحلقات · مزامنة الحالة تلقائيًا مع تقدّم الحلقات ·
تصدير JSON · بحث داخل المكتبة والملاحظات · وقت المشاهدة التقريبي · رسم شهري للإنجاز ·
كتالوج احتياطي عند انقطاع المزوّدات · بدائل بصرية للبوسترات المفقودة · sitemap/robots/JSON-LD ·
اختبارات آلية تشمل اختبارًا يمنع وجود أي مسار بث/رفع.
